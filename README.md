# Ejercicios de Python - ADSO

Colección de ejercicios de práctica realizados durante el aprendizaje de Python. Incluye ejemplos pequeños y programas de consola.

## Temas

- Fundamentos: operadores, variables y cadenas de texto.
- Colecciones: listas, tuplas, conjuntos y diccionarios.
- Control de flujo: condicionales y bucles.
- Funciones y programación orientada a objetos.
- Programas de consola: calculadoras, conversión de monedas, tienda, mascota virtual y registro de un torneo de baloncesto.

## Cómo ejecutar

Se requiere Python 3. Ejecuta desde una terminal, por ejemplo:

```bash
python 00_hola_mundo.py
```

Los ejercicios usan la biblioteca estándar y solicitan datos por consola cuando corresponde.

## Alcance

Son prácticas de aprendizaje, no aplicaciones listas para producción. Las tasas del conversor de monedas son valores fijos de ejemplo y no representan tasas actuales.
